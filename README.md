# Pikmin-3-Randomizer

release : https://github.com/Chokapy/Pikmin-3-Randomizer/releases

# How to use :
1. copy the "Pikmin3randomizer" folder from the "asset" folder into the "mod-file" folder
2. run the randomizer.exe
3. a window will appear and choose you option here
4. then it "randomize" button
5. when the randomization is done it the "pack" button
6. then get your randomized Pikmin 3 in the "mod-file" folder
